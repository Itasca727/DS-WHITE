# DS WHITE

一个只为你亮着的对话窗口。基于 DeepSeek API 的对话本地网页工具：打开即用，手机、电脑都能装。

**在线使用**：https://christinemal721-spec.github.io/DS-WHITE/

## 开始使用

### 直接打开

打开上面的链接，在「设置 › 数据管理」里填入你自己的 DeepSeek API Key 即可。

- API Key 只保存在你自己的设备上，不会上传到任何地方，导出的备份里也不包含它。
- 每个人使用自己的 Key，费用各自结算。

### 装到主屏幕或桌面

| 设备 | 操作 |
| --- | --- |
| iPhone / iPad | 用 Safari 打开 › 分享 › 添加到主屏幕 |
| 安卓 | 用 Chrome 打开 › 右上角菜单 › 安装应用（或「添加到主屏幕」） |
| 电脑 | 用 Chrome / Edge 打开 › 地址栏右侧的「安装」图标 |

### 更新到最新版本

先在「设置 › 数据管理」里导出全部历史对话（zip），再删除主屏幕 / 桌面上的快捷方式（删除会一并清掉本地对话），然后重新打开上面的链接并刷新，即可更新到最新版本。重新添加到主屏幕后，在设置里导入 zip 就能找回全部对话。

### 设备差异

- 界面主要按 iPhone 打磨，安卓和电脑同样可用。
- 震动反馈仅在手机上有。
- 自动备份「静默覆盖文件」仅支持电脑版 Chrome / Edge。iPhone / iPad 等其他设备上只是「备份提醒」：网页不能自己把文件存进手机，必须点提醒里的「存到文件」才算真正保存，不点的话备份只留在浏览器里，清缓存时会一起丢失。

## V1.0 特色功能

- **全量交接官端历史**：直接导入 DeepSeek 官方导出的历史对话 ZIP，对话、图片原件和重新生成的各个版本原样迁入；导出为同一格式；覆盖导入前自动留快照；可开启每 10 轮自动备份（iPhone 等设备上为备份提醒，需手动点保存）。
- **API 用量一键跳转**：在设置里查询账户余额，一键前往充值。当前仅支持查询跳转 DeepSeek API，但不影响其他模型使用。
- **上下文 1M 不断片**：逐轮管理哪些对话进入请求（可一键只带最近 5 轮 / 10 轮），可手动压缩最早 N 轮；开启自动压缩后（设置和上下文管理里是同一个开关），接近 1M token 上限时先由模型整理摘要再继续。
- **搜索对话**：独立的搜索页从按钮原地展开，搜遍全部对话的每一条消息，关键词高亮，点结果直达那条消息，边缘右滑返回。
- **按轮删除对话**：长按任意消息进入多选，整轮删除（含重新生成的版本），后面的对话自动接上；上下文管理、摘要、导出与搜索同步更新。
- **交互反馈**：统一的「冷光浮现」开合动效、触感与轻音效、按钮冷光涟漪、跟手滑动、开屏签名接力。
- **更多细节**：五档字体、朗读音色「暗潮」、语音输入后自动恢复扬声器音量、深浅双主题、深度思考自动折叠、离线可打开。

## 近期更新

**V1.0.2（2026-11-17）**

- **生成不卡顿**：回答不再一个字一个字地蹦，改为一小段一小段匀速输出，长对话里生成时明显更流畅。
- **加粗修复**：`**` 紧挨中文标点时（如 `**标题：**内容`、`**“引号”**`、`**《书名》**`）以前整段显示星号，现在正常加粗。
- **LaTeX 公式**：单独一行的 `$$ 公式 $$`、首尾和内容写在同一行的公式块、没包 `$$` 的 `\begin{aligned}` 等公式环境、表格里的 `$|x|$` 都能正确渲染；支持 `\abs`、`\norm`、`\dd` 等常用命令；渲染不了的公式以源码显示。
- **LaTeX 卡片**：模型用 `\colorbox` + `tabular` + `\hfill` 画的状态栏、通讯录之类卡片现在能渲染出来（自动转换成等价写法，并清除夹在里面的零宽字符）。
- **其他格式**：`~~删除线~~`、`<sup>` `<sub>` `<kbd>` `<mark>` 等 HTML 小标签、`<details>` 折叠块正常显示；`$5 到 $10` 这类金额、`\[1\]` 文献角标不再被误认成公式；`1~2 天` 的范围写法不受影响。
- **图片预览**：点消息里的图片在当前页放大预览，不再跳新页面；点图片可放大并拖动查看。
- **备份说明更准确**：iPhone / iPad 上「自动备份」改名「备份提醒」，提醒文案改为「备份已生成，还没保存」，设置里写明必须点「存到文件」才算保存；没保存过的备份会标出来，错过提醒可以手动保存。
- **上下文管理**：新增「仅最近 10 轮」。
- **界面细节**：侧栏签名改为静止；等待回复时的「眼睛」换成三颗依次亮起的小光点；深度思考进行中，图标带一圈微光和缓慢流转的散点光。
- **首次使用说明**：重新排版，顶部加签名 logo，三条说明改为带图标和小标题的卡片。
- **联系作者**：侧栏底部新增「联系作者」，展开和关闭方式与搜索页一致，内有版本说明和反馈邮箱。

**V1.0.1（2026-11-16）**

- **搜索**：不再只给前 50 段对话，搜全部对话的每一条消息；从最近的对话往前找，边搜边出结果；点结果直接滚到命中的那条消息并闪一下标出来。某段对话数据异常时只跳过那一段，不影响其他结果。
- **导入大文件**：支持 ZIP64 格式（超过 4GB 或文件很多的压缩包）；导入时少占约一半存储空间；显示导入进度百分比；失败时说明具体原因（如设备空间不足）；当前对话太大来不及先备份时，会询问是否直接覆盖。解压后又重新压缩的 zip（外面多一层文件夹、顺序打乱、混进 __MACOSX 等系统文件）也能直接导入。
- **图片报错修复**：修复「You have uploaded an unsupported image」导致之后每条消息都发不出去的问题。模型只接受 JPEG / PNG / GIF / WebP，现在其他格式（BMP、TIFF、AVIF、SVG 等）上传前自动转成 JPEG；转不了的只在界面显示、不再发送；服务端仍拒收时会自动剔除那张图并重发。已经报错的对话更新后直接再发一句即可恢复。
- **自动压缩合并**：上下文管理里的「自动压缩」和设置里的「自动压缩上下文」合并为同一个全局开关，在上下文管理里开启时会先弹确认。旧版按 token 预算压缩的选项已移除。
- **设置下拉关闭**：手机上按住设置面板往下拖即可关闭，轻拖会弹回；左右滑动仍是切换分组。
- **首次使用说明**：第一次打开时，开屏动画后弹出使用说明（本地存储与导出提醒、更新方式、费用说明），点「我已知晓」后不再出现。

## 版本说明与反馈

DS WHITE V1 仅做纯净功能性版本，目的是提供一套完全依托网页端和个人本地文件管理的解决方案。为最大程度保证网页缓存稳定，除了继续打磨交互手感和排查必要的 bug，不会再加入额外功能，包括且不限于 RAG、向量库、外接记忆库、世界书、角色卡、主动调用等。

## 自己部署一份

不需要服务器，任选一种：

- **GitHub Pages**：Fork 本仓库 › Settings › Pages › Source 选「GitHub Actions」。之后每次推送到 `main` 都会自动构建发布，地址为 `https://你的用户名.github.io/DS-WHITE/`。
- **Vercel / Cloudflare Pages / Netlify**：导入仓库，构建命令填 `pnpm build`，输出目录填 `dist`。

必须使用 HTTPS 访问，才能离线使用和安装到主屏幕。

## 本地开发

需要 Node.js 22.12+ 和 pnpm：

```sh
pnpm install
pnpm dev      # 打开 http://localhost:8090
pnpm build    # 产物在 dist/
```
